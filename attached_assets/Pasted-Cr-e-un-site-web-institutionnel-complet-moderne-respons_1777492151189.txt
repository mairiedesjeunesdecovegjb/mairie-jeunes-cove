Crée un site web institutionnel complet, moderne, responsive et sécurisé pour la **Mairie des Jeunes de Covè (Bénin)** avec un panneau d’administration caché.

## OBJECTIF
Créer une plateforme officielle élégante qui présente la mairie des jeunes, ses activités, son équipe, ses projets et ses actualités.

## TECHNOLOGIES À UTILISER
- Frontend : React + Tailwind CSS + Framer Motion
- Backend : Node.js + Express
- Base de données : PostgreSQL ou SQLite
- Authentification admin sécurisée avec session + mot de passe hashé
- Upload images local ou cloudinary
- Site responsive mobile / tablette / desktop

## EXIGENCE MAJEURE
TOUT le contenu du site doit être modifiable depuis l’espace administrateur :

- textes
- titres
- slogans
- photos
- sliders
- équipe municipale
- projets
- événements
- actualités
- contacts
- réseaux sociaux

- couleurs du site
